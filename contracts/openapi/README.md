# OpenAPI

The Story API's OpenAPI document is **emitted by FastAPI**, not
hand-written.

## Live document

When the API is running, the spec is served at:

```
GET /openapi.json
```

(and the interactive docs at `/docs`).

## Committed snapshot

`openapi.json` in this directory is a committed snapshot produced by
`scripts/export_openapi.py`, which imports the app and dumps
`app.openapi()`:

```bash
python scripts/export_openapi.py
# writes contracts/openapi/openapi.json
```

Regenerate it whenever the API surface changes so the committed contract
stays in sync with the code. CI can diff the regenerated file against the
committed one to catch drift.

## Relationship to JSON Schema

- `contracts/schemas/story.schema.json` — the domain/wire **data** shapes
  (generated from the Pydantic `StoryDTO`).
- `contracts/openapi/openapi.json` — the **HTTP surface** (routes,
  request/response bodies), generated by FastAPI.

Keep the three concepts distinct: domain model / API DTO / persistence.
